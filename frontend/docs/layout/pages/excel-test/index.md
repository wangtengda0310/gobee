# Excel Test - 配表测试页面

> File path: `src/pages/excel-test/index.vue`
> Route: `/Excel`

## Overview

配表测试页面用于 Excel 配表的加载、配置、检查和日志查看。采用与功能测试类似的三栏布局，但右侧 Tab 面板内容和底部统计不同。

### ExcelCheckPanel Special Notes

| Feature | Description |
|---------|-------------|
| **虚拟列 "0. 表级校验规则"** | 始终显示在最前面，用于配置整表级别的校验规则，不对应实际 Excel 列。**默认折叠**，点击标题右侧 [▼/▲] 按钮展开/收起 |
| **列级规则卡片** | 根据 Sheet 的列定义动态生成，每张 Excel Sheet 的列都会生成对应的规则卡片 |
| **锚点导航** | 右侧固定 (120px宽)，显示所有规则数量标签，可快速跳转到对应规则 |
| **拖拽排序** | 规则卡片支持拖拽排序，影响检查顺序 |
| **规则类型** | 包含列级规则（如非空、数值范围等）和表级规则（如跨表引用等） |

## Notes

- 树组件展示 Excel 文件和 Sheet
- 右侧 Tab 面板与功能测试页类似但内容不同
- 底部统计包含配表数、Sheet 数、成功/失败数、错误单元格数
- Header 右侧有路径配置输入框（配表目录、用例目录）
- 参数组件目录包含大量检查规则参数配置
