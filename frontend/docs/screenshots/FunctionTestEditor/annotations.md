## 区域标注

| 区域 | 位置 | 对应组件 | 交互说明 |
|------|------|---------|---------|
| A | 顶部导航 | Normal.vue | 页面路由切换 |
| B | Header | n-menu | 加载/保存/执行/停止/设置 |
| C | 左侧树面板 | n-layout-sider | 用例分类树 |
| C1 | 搜索框 | n-input | 模糊搜索用例 |
| C2 | 开关 | n-switch | 过滤/显示描述 |
| C3 | 树形控件 | n-tree | 用例分类结构，支持拖拽 |
| D | Tab栏 | n-tabs | 切换配置/步骤/日志 |
| D1 | 用例配置 | InitYanWuPanel | 演武场初始化配置 |
| D2 | 用例步骤 | StepsPanel | 测试动作配置 |
| D3 | 执行日志 | RobotTestLog | 执行结果展示 |
| E | Footer | n-statistic | 用例/动作数量统计 |

## 右键菜单

树节点右键菜单选项：
- 新建分类
- 新建用例
- 重命名
- 删除
- 复制用例

## Modal 弹窗

| 弹窗 | 触发 | 功能 |
|------|------|------|
| AddCateModal | 右键→新建分类 | 添加分类 |
| AddCaseModal | 右键→新建用例 | 添加用例 |
| RenameCaseModal | 右键→重命名 | 重命名用例 |
| RenameCateModal | 右键→重命名 | 重命名分类 |
| OptionModal | Header→设置 | 应用设置 |
