## 区域标注

| 区域 | 位置 | 对应组件 | 交互说明 |
|------|------|---------|---------|
| A | 顶部导航 | Normal.vue | 页面路由切换 |
| B | 配置区 | 内联 flex 布局 | 路径配置和执行按钮 |
| C | 结果列表 | n-scrollbar | 错误信息卡片 |

## 配置区详解

```
┌──────────────────────────────────────────────────────────────────────┐
│ 配表位置: [输入框] Card文件夹位置: [输入框] [开始检索]               │
│     ↑              ↑                                                 │
│  excelDir        cardDir                                             │
│ (Excel目录)      (Card文件夹，用于拼接Audio路径)                     │

```

## 错误卡片详解

```
┌──────────────────────────────────────────────────────────────────────┐
│ 武将: 武将名(ID)                    ← 武将标识                       │
│ 音频Id: xxx                         ← 问题音频ID                     │
│ 重复使用次数: N                     ← 该音频被使用的次数             │
│ 使用位置: 位置1 位置2 位置3         ← 在哪些地方使用                 │
│ 原因: 文件不存在/重复使用           ← 错误原因                       │
└──────────────────────────────────────────────────────────────────────┘
```

## 检查逻辑

1. 根据 cardDir 拼接 Audio 目录路径
2. 遍历武将的音频配置
3. 检查音频文件是否存在
4. 检测重复使用的音频

## 结果数据结构

```typescript
interface VoiceCheckReport {
  HeroLineVoiceRepeatVoiceMap: {
    [heroName: string]: {

      }

  }
  HeroAudioRepeatVoiceMap: { ... }
}
```

## 交互说明

| 操作 | 说明 |
|------|------|
| 点击"开始检索" | 执行语音资源检查 |
| 滚动结果列表 | 查看所有错误项 |

## 错误类型

| 错误 | 说明 |
|------|------|
| 文件不存在 | 音频文件路径错误或文件缺失 |
| 重复使用 | 同一音频被多个地方使用 |
