## 名字标黄逻辑

武将名字显示为黄色表示该武将存在于差异结果中（有变更记录）：
- 条件: `HeroesDiff[EHeroId]?.ChangeCount` 存在

## 交互说明

### 统计标签点击
- 点击"新增"/"删除"/"修改"标签可筛选对应类型
- 再次点击取消筛选

### 武将面板
- Tab 切换查看不同信息
- 滚动浏览武将列表

### 锚点导航
- 点击跳转到对应武将
- 自动高亮当前可见武将

## 数据加载流程

```
点击"执行检查"
    │
    ▼
HeroWikiResCheckService.Check(excelDir, jsonPath)
    │
    ▼
返回 diffExcels 数据
    │
    ├──► 计算统计 (总变化/新增/删除/修改)
    │
    ├──► 渲染武将列表
    │
    └──► 生成锚点导航
```
