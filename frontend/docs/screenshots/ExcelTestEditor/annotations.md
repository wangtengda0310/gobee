## 区域标注

| 区域 | 位置 | 对应组件 | 交互说明 |
|------|------|---------|---------|
| A | 顶部导航 | Normal.vue | 页面路由切换 |
| B | Header 左侧 | n-menu | 加载配表/保存用例/执行检查 |
| C | Header 右侧 | PathConfigInput | 配表目录 + 用例目录配置 |
| D | 左侧树面板 | n-layout-sider | xlsx/Sheet 树形结构 |
| D1 | 搜索框 | n-input | 模糊搜索 Sheet |
| D2 | 树形控件 | n-tree | xlsx 文件 → Sheet 列表 |
| E | Tab栏 | n-tabs | 切换负责人/配置/日志 |
| E1 | 负责人 | ExcelCheckManager | Sheet 负责人管理 |
| E2 | 用例配置 | ExcelCheckPanel | 列级/表级规则配置 |
| E3 | 执行日志 | ExcelCheckLog | 检查结果展示 |
| F | Footer | n-statistic | 文件/Sheet/错误统计 |

## Footer 统计说明

| 统计项 | 颜色 | 说明 |
|--------|------|------|
| xlsx文件数 | 默认 | 加载的 Excel 文件总数 |
| Sheet数 | 默认 | 所有 Sheet 总数 |
| 成功Sheet | 绿色 | 检查通过的 Sheet |
| 错误Sheet | 黄色 | 检查失败的 Sheet |
| 错误单元格 | 红色 | 本次检查的错误数 |

## 与 FunctionTestEditor 的区别

| 对比项 | FunctionTestEditor | ExcelTestEditor |
|--------|-------------------|-----------------|
| Header 右侧 | 无 | PathConfigInput |
| 树形结构 | 分类→用例 | xlsx→Sheet |
| Tab 数量 | 3个 | 3个 (内容不同) |
| 右侧锚点 | 仅用例步骤Tab | 用例配置Tab |

## 交互说明

### 树形控件
- 点击 xlsx 展开 Sheet 列表
- 点击 Sheet 加载对应配置
- 右键菜单：配置操作

### 路径配置
- 失焦自动保存
- 支持手动触发保存

### Tab 切换
- 负责人：管理各 Sheet 的负责人
- 用例配置：配置检查规则
- 执行日志：查看检查结果
