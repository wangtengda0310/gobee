# 表级规则变更检测 - 实现详解

变更检测是表级规则的内置功能，支持行列级别的增删改检测。

## 概述

| 特性 | 说明 |
|------|------|
| 配置方式 | 内置功能，与表级规则并列，无需单独 JSON 配置 |
| 数据来源 | Git 历史版本对比(`git show HEAD~1:path`) |
| 检测类型 | 新增行/列、删除行/列、字段值变更 |
| 持久化 | 无，纯内存计算(不生成快照文件) |

## 核心流程

```
NewRowNotifyRule.Check() 或 RowChangeNotifyRule.Check()
│
├── 1. 从 sheetMap 中找到目标 Excel 文件路径
│
├── 2. GetFileAtCommit(gitRepoPath, baseCommit, excelPath)
│      └── 执行: git -C <repo> show HEAD~1:<relative_path>
│
├── 3. ParseExcelFromBytes(oldContent, sheetName)
│      └── excelize.OpenReader(bytes.NewReader(content))
│
├── 4. BuildSnapshot(sheetName, oldCols, startRowIdx, idCol, nameCol)
│      └── 将 [][]string 转为 map[ID]*RowSnapshot(内存数据结构)
│
├── 5. DetectDiff(oldSnapshot, currentCols, startRowIdx, idCol, nameCol)
│      ├── BuildSnapshot() 构建当前数据的内存视图
│      ├── DetectColChanges() 对比列名变化
│      └── 逐行对比：新增行 / 删除行 / 修改行
│
└── 6. 根据通知开关参数构建通知消息
```

## 关键函数

**位置**: `xlsx/check_internal/excel_diff.go`

| 函数 | 说明 |
|------|------|
| `GetFileAtCommit()` | 使用 `git show` 获取指定 commit 的文件二进制内容 |
| `ParseExcelFromBytes()` | 从字节流解析 Excel，返回按列存储的二维数组 |
| `BuildSnapshot()` | 将列数据转换为以 ID 为 key 的内存 map(纯内存，无文件 I/O) |
| `DetectDiff()` | 对比新旧数据，返回增删改差异 |
| `DetectColChanges()` | 对比列名列表，检测新增/删除列 |
| `FormatDiffNotification()` | 格式化差异通知文本 |

## 核心数据结构

**位置**: `xlsx/check_internal/excel_diff.go`

| 结构 | 说明 |
|------|------|
| `ExcelSnapshot` | 内存中的 Excel 数据视图(SheetName, ColNames, Rows) |
| `RowSnapshot` | 以 ID 为 key 的行数据(Id, Name, Data, RowIndex) |
| `ExcelDiffResult` | 差异结果(AddedRows, RemovedRows, ModifiedRows, AddedCols, RemovedCols) |
| `RowChange` | 行变更信息(RowIndex, RowId, RowName, Changes) |
| `FieldChange` | 字段变更信息(ColName, OldValue, NewValue) |

> 注意：`ExcelSnapshot` / `RowSnapshot` 是纯内存数据结构，仅用于将 `[][]string` 转换为以 ID 为 key 的 map 以便对比，不涉及文件 I/O。

## 检测逻辑

### 行变化检测

| 类型 | 检测方式 |
|------|----------|
| 新增行 | `newSnapshot.Rows` 存在但 `oldSnapshot.Rows` 不存在 |
| 删除行 | `oldSnapshot.Rows` 存在但 `newSnapshot.Rows` 不存在 |
| 修改行 | 同一 ID 下，对比每个字段的值 |

### 列变化检测

使用 `DetectColChanges` 函数对比 `ColNames` 数组，检测新增/删除的列。

## 规则参数

### NEW_ROW_NOTIFY

| 参数 | Key | 说明 | 默认值 |
|------|-----|------|--------|
| ID列名 | `idColName` | 用于标识行的 ID 列名 | `Id` |
| 名称列名 | `nameColName` | 用于标识行的名称列名 | `Name` |
| Git仓库路径 | `gitRepoPath` | Git 仓库根目录路径 | `.`(自动取 Excel 所在目录) |
| 基准Commit | `baseCommit` | 对比的基准 commit | `HEAD~1` |
| 通知新增行 | `notifyAddedRows` | 是否生成新增行通知 | `true` |
| 通知删除行 | `notifyRemovedRows` | 是否生成删除行通知 | `true` |
| 通知新增列 | `notifyAddedCols` | 是否生成新增列通知 | `true` |
| 通知删除列 | `notifyRemovedCols` | 是否生成删除列通知 | `true` |

### ROW_CHANGE_NOTIFY

| 参数 | Key | 说明 | 默认值 |
|------|-----|------|--------|
| ID列名 | `idColName` | 用于标识行的 ID 列名 | `Id` |
| 名称列名 | `nameColName` | 用于标识行的名称列名 | `Name` |
| Git仓库路径 | `gitRepoPath` | Git 仓库根目录路径 | `.`(自动取 Excel 所在目录) |
| 基准Commit | `baseCommit` | 对比的基准 commit | `HEAD~1` |
