## ARENA_SEASON_CHECK

> 竞技场赛季检查(源表 ArenaSeason)

### Bug 修复记录 (2026-04-16)

**问题**：用户输入错误的 `timeRangeBefore` 参数格式（如 `"7天"`、`"168"`）时，规则直接报错"无法解析时间参数"，中断检查。

**修复**：在 `table_check_arena_season.go:59-65` 添加容错处理，解析失败时回退到默认值 `168h`。

**单元测试(9/9 通过)**：正常场景、警告场景、失败场景、缺少列、空数据、错误格式容错、空参数容错、纯数字容错。

```bash

```
