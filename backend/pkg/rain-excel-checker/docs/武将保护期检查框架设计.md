# 武将保护期检查框架设计

> 状态：已实现（HERO_DROP_CHECK / HERO_SYNTHESIS_CHECK / DRAWFIX_PROTECTION_CHECK / DRAWFIX_ARENA_PROTECTION_CHECK 等规则已完整开发）

## 业务背景

游戏中有**战令系统**（周期性充值活动）和**大将军系统**（竞技场赛季段位奖励）：
- **战令**：每期战令配置专属武将作为高级奖励，保护期内（SeasonPass.StartTime + 4个月）不开放
- **大将军**：竞技场赛季大将军段位奖励专属武将，保护期内（至 ArenaSeason.SeasonEndTime）不开放

**问题**：策划配表时可能因配置错误，导致专属武将在保护期内被意外开放到其他系统（定向招募、商店、合成等）中。

**目标**：构建检查框架，检测"战令/大将军武将在保护期内出现在了不该出现的系统中"。

## 数据关系链

### 已确认的表关联

```
定向招募表|DrawFix
├── Id (int)          活动id
├── Name (string)     名称
├── StartTime (string) 开始时间
├── EndTime (string)   结束时间
├── ItemIds ({int;bool}[])  武将道具列表（ItemId + MustHave标记）
└── SlotNum (int)     槽位数量

道具表|Item
├── Id (int)          道具ID
├── Type (EItemType)  道具类型（Hero=武将道具）
├── ItemParam (int[]) 道具参数（Type=Hero时，ItemParam[0]=武将ID）
└── ...

武将表|Hero
├── Id (int)          武将ID
├── Name (string)     武将名称
├── IsOpen (bool)     是否开放
├── OpenDate (string) 开放时间
└── ...

赛季战令表|SeasonPass / 赛季战令奖励表|SeasonPassReward
├── Id / SeasonPassId
├── StartTime / EndTime
├── HighReward (ItemCfg[]) 高级奖励（包含武将道具）
└── ...
```

### 关联路径

```
DrawFix.ItemIds.ItemId → Item(Type=Hero).ItemParam[0] → Hero.Id
SeasonPassReward.HighReward.ItemId → Item(Type=Hero).ItemParam[0] → Hero.Id
SeasonPassReward.SeasonPassId → SeasonPass.Id → StartTime/EndTime
ArenaScoreReward.Reward → Item(Type=Hero).ItemParam[0] → Hero.Id
ArenaScoreReward.Season → ArenaSeason.Id → SeasonStartTime/SeasonEndTime
```

以 Hero 为中心的三条关系链：

```
链1: Hero ← Item(Type=Hero,ItemParam) ← DrawFix.ItemIds → DrawFix.StartTime/EndTime
链2: Hero ← Item(Type=Hero,ItemParam) ← SeasonPassReward.HighReward → SeasonPass.StartTime/EndTime
链3: Hero ← Item(Type=Hero,ItemParam) ← ArenaScoreReward.Reward → ArenaSeason.SeasonEndTime
```

比较规则：链1的时间区间不能与链2或链3的保护期区间重叠。

### 道具ID到武将ID的映射

| 路径 | 方法 | 说明 |
|------|------|------|
| 直接映射 | `IsHeroItem(itemId)` + `ExtractHeroIdFromItemCfg(itemId)` | 道具ID范围 1001000-1099999 → 武将ID = itemId % 100000 |
| 语义映射 | Item 表 Type="Hero" → ItemParam[0] | 通过 Type 字段过滤，ItemParam 存储武将ID |

**推荐使用语义映射**（Type + ItemParam），因为它有明确的业务约束。

## 方案对比

### 方案A：系统出发（正向推理）

对每个系统编写独立规则文件，从目标表提取武将列表后与保护期做交集判断。

| 维度 | 评分 |
|------|------|
| 实现难度 | 低 — 符合现有 TableRuleMeta 体系 |
| 代码复用 | 中 — 战令武将提取可复用 |
| 可配置性 | 低 — 关系链硬编码 |

### 方案B：Hero 出发（Map/Reduce 反向推理）

对每个 Hero：Map 提取各系统时间区间 → Reduce 比较是否重叠。

| 维度 | 评分 |
|------|------|
| 实现难度 | 高 — 需设计通用求值器和关系链 DSL |
| 代码复用 | 高 — 新增系统只需声明关系链 |
| 可配置性 | 高 — 关系链声明式、可配置 |

### 方案C（推荐）：折中方案

以方案B的设计思想为核心，兼容方案A的现有架构。

## 折中方案设计

### 核心思想

1. **关系链配置层**：用结构化的 Go struct 描述"从 Hero 到目标系统"的关系链
2. **通用求值器**：一个 Go 函数根据关系链配置执行检查
3. **兼容现有体系**：每条关系链注册为一个 `TableRuleMeta`
4. **前端可展示**：关系链配置可通过 MCP/API 暴露给前端

### 关系链配置结构

关系链配置结构定义参见 `helpers/hero_rule_helper.go` 中的相关类型：
- `HeroProtectionChain` — 武将保护期关系链
- `HeroSourceConfig` — 从目标表提取武将的配置
- `ProtectedSourceConfig` — 保护期来源配置
- `ProtectionCompareRule` — 比较规则

### 通用求值器工作流程

```
输入: HeroProtectionChain 配置 + SheetMap（所有表数据）

步骤1: 提取受保护武将集合
  - 从 SeasonPassReward + SeasonPass 获取每期战令的专属武将
  - 计算保护期截止时间 = StartTime + ProtectMonths
  - 输出: map[heroId]ProtectedPeriod{StartTime, ProtectUntil}

步骤2: 从目标表提取武将-时间映射
  - 遍历目标表（如 DrawFix）的每一行
  - 解析 HeroSource.ItemField 字段 → 获得道具ID列表
  - 通过 Item 表 Type=Hero + ItemParam 关联到武将ID
  - 从目标行的 StartTime/EndTime 字段提取时间区间
  - 输出: []TargetEntry{RowIdx, HeroId, HeroName, StartTime, EndTime}

步骤3: 交集检查
  - 对每个 TargetEntry，检查其 HeroId 是否在受保护武将集合中
  - 如果是，比较时间区间：
    - TargetEntry.EndTime < ProtectUntil → 错误：战令武将在保护期内被开放
    - TargetEntry.StartTime >= ProtectUntil → 正常：保护期已过
    - 区间有重叠 → 警告/错误

步骤4: 输出检查结果（TableCheckResult，与现有体系一致）
```

### 新增系统的扩展流程

未来新增一个系统（如商店 Shop）的检查，只需：

1. 定义一条 HeroProtectionChain 配置
2. 注册为一个 TableRuleMeta
3. 不需要编写新的检查逻辑代码

## 排查指南

### 数据流图

战令路径：SeasonPassReward.HighReward → 提取武将道具ID → Hero.Id（获取名称）
         SeasonPassReward.SeasonPassId → SeasonPass.Id → StartTime（保护期起算点）
         DropItem.Item → 匹配武将道具ID → DropItem.ValidDate（合成开放时间）

大将军路径：ArenaScoreReward.Reward(DanName含大将军) → 提取武将道具ID → Hero.Id
           ArenaScoreReward.Season → ArenaSeason.Id → SeasonEndTime（保护期截止时间）
           DropItem.Item → 匹配武将道具ID → DropItem.ValidDate（合成开放时间）

### 各时间字段的来源表

| 时间字段 | 来源表.字段 | 含义 | 使用规则 |
|----------|-------------|------|---------|
| StartTime | SeasonPass.StartTime | 战令开始时间（保护期起算点） | HERO_DROP, HERO_SYNTHESIS, DRAWFIX_PROTECTION |
| EndTime | SeasonPass.EndTime | 战令结束时间 | HERO_DROP |
| SeasonStartTime | ArenaSeason.SeasonStartTime | 赛季开始时间 | HERO_SYNTHESIS（反向检查）, DRAWFIX_ARENA_PROTECTION |
| SeasonEndTime | ArenaSeason.SeasonEndTime | 赛季结束时间（大将军保护期截止） | HERO_SYNTHESIS, DRAWFIX_ARENA_PROTECTION |
| ValidDate | DropItem.ValidDate | 掉落/合成生效时间 | HERO_SYNTHESIS |
| ExpireDate | DropItem.ExpireDate | 掉落/合成过期时间 | HERO_DROP |
