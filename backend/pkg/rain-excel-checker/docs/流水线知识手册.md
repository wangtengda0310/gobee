# CI/CD 流水线知识手册

本文档记录 rain-excel-checker 在蓝鲸 CI/CD 平台上的流水线配置和运行要点。

## 1. 当前流水线配置

### 3.1 基本信息

- **流水线名称**: 配表检查-测试
- **项目**: xcard
- **URL**: https://devops.devcloud.ztgame.com/projects/xcard/pipelines/p-5e007d6a5e3e472e9b3abb99b48e1064

### 3.2 启动变量


### 3.3 流水线步骤

```
配表检查-测试
│
├── 阶段1: 测试全量检查配表
│   ├── 拉取代码(GIT)            # 插件：拉取 rain-excel-checker
│   ├── 拉取代码(GIT)(飞书库)    # 插件：拉取 feishu-lib
│   ├── 拉取代码(GIT)(excel配表) # 插件：拉取 xcard-excel-config
│   ├── 拉取代码(GIT)(用例)      # 插件：拉取 rain-qa-func
│   ├── 构建go可执行程序           # Shell: go build
│   └── 执行检查                  # Shell: 运行检查
│
└── 阶段2: 使用新版校验工具增量校验全表规则
    ├── Shell 脚本                # 主检查脚本(Docker 执行)
    ├── 拉取代码(GIT)            # 插件
    └── Shell 脚本                # 其他脚本
```

## 4. CI/CD 环境变量(蓝鲸平台)

| 变量 | 含义 |
|------|------|
| `BK_CI_START_USER_NAME` | 触发人 |
| `BK_CI_HOOK_BRANCH` | 触发分支 |
| `BK_CI_HOOK_REVISION` | 提交 ID |
| `BK_CI_START_TYPE` | 触发方式(代码变更/手动) |

## 5. Docker 容器执行注意事项

> Docker 配置和挂载示例详见 [scripts/Dockerfile](../../scripts/Dockerfile) 和 [scripts/ci_pipeline.sh](../../scripts/ci_pipeline.sh)。

### 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| git 命令失败 | 容器内没有 git | 预装 git 或使用包含 git 的镜像 |
| 无法获取历史版本 | 只映射了子目录，没有 .git | 映射整个 git 仓库 |
| 路径不匹配 | 容器内路径与脚本预期不同 | 调整参数或挂载路径 |

## 6. 最佳实践

### 6.1 镜像管理

- 使用预构建镜像，避免每次安装依赖
- 将常用工具(git、bash)打包到镜像中
- 使用私有镜像仓库加速拉取

### 6.2 脚本维护

- 脚本应纳入 git 版本控制
- 使用相对路径或环境变量，避免硬编码
- 添加必要的日志输出便于调试

### 6.3 安全注意事项

- 不要在脚本中硬编码敏感信息(密码、Token)
- 使用平台凭据管理功能
- 编辑流水线前先确认不会误触发
