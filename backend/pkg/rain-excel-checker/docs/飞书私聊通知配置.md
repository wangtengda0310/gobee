# 飞书私聊通知配置指南

## 概述

rain-excel-checker 支持向校验失败的 git 提交者发送飞书私聊通知。私聊通知与群消息通知是独立的两个通道，通过不同的凭证配置。

## 凭证来源

| 凭证 | 来源 | 说明 |
|------|------|------|
| 群消息 webhook | `-feishuRobot` 命令行参数 | 飞书机器人 webhook GUID |
| 私聊 App ID | `FEISHU_DM_APP_ID` 环境变量 | 独立飞书应用的 App ID |
| 私聊 App Secret | `FEISHU_DM_APP_SECRET` 环境变量 | 独立飞书应用的 App Secret |

私聊凭证**仅通过环境变量传递**，不使用命令行参数，避免出现在 `ps aux` 中导致泄露。

## 飞书应用创建步骤

1. 登录 [飞书开放平台](https://open.feishu.cn/)
2. 创建企业自建应用
3. 在"权限管理"中开通以下权限：
   - `im:message:send_as_bot` — 以应用身份发送消息
   - `contact:user.employee_id:readonly` — 获取用户 employee_id（如需通过邮箱发送）
4. 发布应用（需要管理员审批）
5. 在"凭证与基础信息"中获取 `App ID` 和 `App Secret`

## 配置方式

### 本地开发

```bash
export FEISHU_DM_APP_ID="cli_xxxxxx"
export FEISHU_DM_APP_SECRET="xxxxxx"
go run main.go -excelPath=../../config/excel
```

### CI 流水线

在流水线环境变量中配置：

```bash
# Jenkins / GitLab CI / Blue Ocean
export FEISHU_DM_APP_ID="${FEISHU_DM_APP_ID}"
export FEISHU_DM_APP_SECRET="${FEISHU_DM_APP_SECRET}"
rain-excel-checker -excelPath=/path/to/config -casePath=/path/to/cases
```

### Docker 容器

1. 复制 `.env.example` 为 `.env` 并填写：

```bash
cd docker
cp .env.example .env
# 编辑 .env，填入 FEISHU_DM_APP_ID 和 FEISHU_DM_APP_SECRET
```

2. `docker-compose.yml` 已配置环境变量传递（无需修改）

3. 启动容器：

```bash
docker-compose up analyzer
```

## 通知策略

私聊通知的发送由分支名决定，详见 `dispatch/strategy.go`：

| 分支 | 群消息 | 私聊 |
|------|--------|------|
| `v0.0.8-pre-release` | 发送 | 不发送 |
| 其他分支 | 不发送 | 发送 |

## 禁用私聊

如需临时禁用私聊通知，使用 `-noDM` 参数：

```bash
go run main.go -excelPath=../../config/excel -noDM
```

## 常见问题

**Q: 私聊通知不发送？**
- 检查 `FEISHU_DM_APP_ID` 和 `FEISHU_DM_APP_SECRET` 是否正确设置
- 检查飞书应用是否已发布并通过权限审批
- 检查提交者邮箱是否能在飞书系统中找到对应用户
- 使用 `-noDM=false` 确认未禁用

**Q: 群消息和私聊都想发？**
- 当前策略是互斥的（预发布分支只发群消息，其他分支只发私聊）
- 如需同时发送，修改 `dispatch/strategy.go` 中的 `DefaultRules()` 或 `DefaultMode()`
