# 飞书机器人消息发送机制

本文档描述项目中飞书消息通知的架构和实现方式。

## 1. 整体架构

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                            feishu-lib (公共库)                               │
├─────────────────────────────────────────────────────────────────────────────┤
│  func.go:                                                                   │
│  ├─ sendMsg()                    → HTTP POST 到 Webhook                     │
│  ├─ SendFeiShuRobotText()        → 发送纯文本消息                           │
│  ├─ SendFeiShuRobotCardTemplate()→ 发送模板卡片                             │
│  └─ SendFeiShuRobotCardJson()    → 发送 JSON 2.0 卡片                       │
│                                                                             │
│  json_card_prefab.go:                                                       │
│  └─ NormalBlue()                 → 预设蓝色卡片模板                         │
│                                                                             │
│  vars.go:                                                                   │
│  └─ LJH = "36732a0b-..."         → 默认机器人 GUID                          │
└─────────────────────────────────────────────────────────────────────────────┘
                    │                           │
        ┌───────────┘                           └───────────┐
        ▼                                                   ▼
┌───────────────────────────┐             ┌───────────────────────────────────┐
│   rain-excel-checker      │             │   rain-qa-func (间接使用)          │
│   (直接使用 feishu-lib)    │             │   (通过 rain-robot 使用)           │
├───────────────────────────┤             ├───────────────────────────────────┤
│ 场景: 配表规则检查报告     │             │ 场景: 功能测试完成通知             │
│ 格式: JSON 2.0 卡片        │             │ 格式: 纯文本                       │
└───────────────────────────┘             └───────────────────────────────────┘
```

## 2. rain-qa-func 飞书通知流程

rain-qa-func 通过 rain-robot 间接发送飞书消息，用于功能测试完成通知。

### 2.1 配置层

- 配置结构：`[FuncCaseConfig](internal/functionConfigService.go:25)`
- 存储位置：`.rain-qa-func.json` (section: `function_test`)

### 2.2 传递层

- 调用入口：`[functionCaseService.go:154](internal/functionCaseService.go:154)`
- 变量设置：`[vars.go:56](rain-robot/vars/vars.go:56)`、`[client_yanwu_qa_function.go:64](rain-robot/xcard_client/client_yanwu_qa_function.go:64)`

### 2.3 发送实现

- 消息结构体 + 发送函数：`[client_yanwu_qa_function.go](rain-robot/xcard_client/client_yanwu_qa_function.go)`
- 调用时机：测试完成后（`client_yanwu_qa_function.go:324`）

## 3. rain-excel-checker 飞书通知流程

rain-excel-checker 直接使用 feishu-lib 发送卡片消息，用于配表规则检查报告。

- 命令行参数：`[main.go](rain-excel-checker/main.go)`（`--feishuRobot`）
- 发送卡片：`[main.go:90](rain-excel-checker/main.go:90)`

## 4. feishu-lib API 参考

位置：`feishu-lib/func.go`、`feishu-lib/base_def.go`、`feishu-lib/json_card_prefab.go`

| 函数 | 用途 | 消息类型 |
|------|------|----------|
| `SendFeiShuRobotText(robot, format, args...)` | 纯文本 | `text` |
| `SendFeiShuRobotCardTemplate(robot, template, version, vars)` | 模板卡片 | `interactive` |
| `SendFeiShuRobotCardJson(robot, *JsonCard)` | JSON 2.0 卡片 | `interactive` |

预设模板：`[NormalBlue](feishu-lib/json_card_prefab.go)`

## 5. 环境变量支持

| 变量名 | 默认值 | 说明 |
|--------|--------|------|
| `FEISHU_ROBOT` | `36732a0b-9b65-4456-8294-17044223114f` | 飞书机器人 GUID |
| `SEND_QA_FUNC_LOG_FEISHU` | `false` | 是否发送功能测试日志到飞书 |

## 6. 两种实现对比

| 项目 | 实现位置 | 消息格式 | 依赖 | 使用场景 |
|------|----------|----------|------|----------|
| rain-excel-checker | 直接调用 feishu-lib | JSON 2.0 卡片 | feishu-lib | 配表规则检查 |
| rain-qa-func | 透传给 rain-robot | 纯文本 | rain-robot 内置 | 功能测试通知 |

**关键差异**:

- rain-excel-checker 使用**卡片消息**（美观，支持 Markdown、@ 提及）
- rain-qa-func 通过 rain-robot 发送**纯文本消息**（简单直接）

## 7. Webhook URL 格式

```
https://open.feishu.cn/open-apis/bot/v2/hook/{GUID}
```

GUID 由飞书群组创建自定义机器人时生成。
