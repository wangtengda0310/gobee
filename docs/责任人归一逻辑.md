# 责任人归一逻辑

## 概述

责任人归一是一种树形结构右键菜单功能，用于将分组（分类/Excel文件）下首个有负责人的子节点同步到同组所有子节点。该功能被战斗测试和配表测试共用。

## 使用场景

| 面板 | 分组类型 | 子节点类型 | 负责人字段 |
|------|----------|------------|------------|
| 战斗测试 | 分类 (Categories) | 用例 (Cases) | `caseManager: string` |
| 配表测试 | Excel 文件 (Excel) | Sheet | `QA: string[]`, `Designer: string[]`, `Programmer: string[]` |

## 核心逻辑

### 1. 通用组件

位置: `[use-tree-context-menu.ts](frontend/src/shared/composables/use-tree-context-menu.ts)`

函数签名：`createManagerToOneOption<T extends ManagerChild>(dialog, message, children, field, onSync?)`

参数：`dialog`（确认弹窗）、`message`（结果提示）、`children`（子节点数组）、`field`（负责人字段名）、`onSync`（同步回调）。

执行流程：用户右键分组 → 选择"XX负责人归一" → 确认对话框 → 顺序遍历找到首个有负责人的节点 → 同步到所有子节点 → 标记 modified。

### 2. 支持的字段类型

| 类型 | 使用场景 | 判断条件 | 同步方式 |
|------|----------|----------|----------|
| `string[]` | 配表测试（QA/Designer/Programmer） | `Array.isArray(val) && val.length > 0` | 深拷贝 `[...sourceList]` |
| `string` | 战斗测试（caseManager） | `typeof val === "string" && val !== ""` | 直接赋值 `sourceStr` |

字段标签映射：QA → "QA"，Designer → "策划"，Programmer → "程序"，caseManager → "负责人"。

## 各面板实现

- 字段：`caseManager`（字符串）

### 配表测试

位置: `[use-tree.ts](frontend/src/pages/excel-test/composables/use-tree.ts)`

- 三类负责人分别归一：QA、Designer（策划）、Programmer（程序）
- 数据流向：`excelCheckManagerListMap` → `managerChildren` 数组 → 归一操作 → 写回 Map
- 每类归一完成后显示成功提示

## 注意事项

1. **顺序检索**：归一操作按数组顺序找到首个有负责人的子节点，不是随机选择
2. **深拷贝**：数组类型字段使用深拷贝，避免引用共享
3. **modified 标志**：同步后需要设置 modified 标志，提示用户保存
4. **空值处理**：如果该组没有任何子节点有负责人，会提示错误
5. **类型兼容**：共享组件同时支持 `string[]` 和 `string` 类型的负责人字段
