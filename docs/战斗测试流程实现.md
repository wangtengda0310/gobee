## 执行流程

```
1. 加载用例
   JsonCaseService.ReadJSONFileOrDir() → []QAFuncCase

2. 启动测试
   JsonCaseService.RunRobotTest()
   │
   ├─ 创建可取消上下文
   ├─ 调用 xcard_client.RobotsYanWuQAFunctionCase()
   │   │
   │   ├─ 连接游戏服务器
   │   ├─ 创建/加入房间
   │   ├─ 发送 StartCustomGame (含 InitYanWu)
   │   │
   │   └─ 遍历执行 Steps
   │       │
   │       ├─ 根据 Action 类型执行对应操作
   │       │   ├─ PlayCard → 发送出牌请求
   │       │   ├─ OptRoomAction → 发送操作响应
   │       │   └─ OnlyAsset → 仅等待断言
   │       │
   │       └─ 验证 Assets 断言
   │           ├─ 等待服务器消息
   │           └─ 比对属性值
   │
   └─ 返回测试结果

3. 日志回调
   logChan → Wails3Log → Event.Emit("robotLog")
```
