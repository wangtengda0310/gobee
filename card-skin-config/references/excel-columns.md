# Item.xlsx 列结构参考

> ⚠️ 以下为示例列结构，实际列名和位置需要根据文件确认。
> 首次使用时会自动打印表头，根据打印结果调整列位置。

## 假设的列结构

| 列号 | 可能的列名 | 用途 |
|------|----------|------|
| A | 道具id | 唯一标识，新道具 = 最大值+1 |
| B | 道具类型 | 值 = "CardSkin"，用于筛选 |
| C | 道具名称 | 填入皮肤名称 |
| D | 道具品质 | 精良=2, 卓越=3, 至臻=4 |
| E | 图标icon | 包含拼音的路径，如 `res/card/zhugeliang/icon.png` |
| ... | ... | 其他列保持与上一行一致 |

## 如果自动识别失败

1. 手动打开 Item.xlsx 确认表头
2. 告诉 AI 各列的准确位置和名称
3. 重新执行
