# 手牌皮肤配置

引用 `skills/common-rules.md` 中的通用铁律、检查点和使用记录规则。

## 前置条件

确保以下文件存在：

- `/Users/zt-3803045/.openclaw/workspace/名将杀配置/Item.xlsx` — 道具表
- `/Users/zt-3803045/.openclaw/workspace/名将杀配置/CardSkin_手牌皮肤表.xlsx` — 手牌皮肤表

## 工作流

### 第一步：解析用户需求

从用户输入中提取角色名称，例如"配置诸葛亮的手牌皮肤" → 角色名 = "诸葛亮"。

### 第二步：读取飞书 Wiki 获取皮肤信息

Wiki 地址：`https://ztgame.feishu.cn/wiki/MHZLwRAunieeUfkjm2ecNqrCnfe`

**读取方式（按优先级尝试）：**

1. 先试用 `feishu_sheet` 工具传入 wiki URL 读取
2. 如果 feishu 插件需要 OAuth 授权，提示用户在飞书中授权，然后重试
3. 或者提醒用户手动导出该表格并告知内容

**提取信息：**

该 Wiki 是一个电子表格，需要找到【手牌皮肤】工作表（sheet/页签），在该工作表中：

- 在【主题】列中找到用户指定的角色名（如"诸葛亮"）
- 提取该行以下字段：
  - **皮肤名称** — 用于 Item.xlsx 的道具名称 和 CardSkin 表的皮肤名称
  - **命名拼音** — 用于替换图标和路径中的拼音部分
  - **等级** — 用于道具品质映射

### 第三步：修改 Item.xlsx

使用 Python 脚本 `scripts/modify_excel.py` 完成，或手动执行以下步骤：

#### 3.1 定位插入位置

在 Item 表中找到**道具类型为 CardSkin**且**道具id 最大**的那一行。

#### 3.2 复制并插入新行

1. 复制该行的**全部配置**
2. 在该行**下方**插入新行
3. 粘贴复制的内容

#### 3.3 修改新行内容

按以下规则修改：


| 字段         | 修改规则                       |
| ---------- | -------------------------- |
| **道具id**   | 上一行道具id值 + 1               |
| **道具名称**   | 填入从第二步获取的**皮肤名称**          |
| **道具品质**   | 根据等级映射：精良=2，卓越=3，至臻=4      |
| **图标icon** | 将原有拼音名称部分替换为第二步获取的**命名拼音** |


#### 3.4 保存

保存 Item.xlsx，**记录新生成的 道具id**，供下一步使用。

### 第四步：修改 CardSkin_手牌皮肤表.xlsx

#### 4.1 定位插入位置

在 CardSkin 表中找到**手牌皮肤道具id 最大**的那一行。

#### 4.2 复制并插入新行

1. 复制该行的**全部配置**
2. 在该行**下方**插入新行
3. 粘贴复制的内容

#### 4.3 修改新行内容

按以下规则修改：


| 字段            | 修改规则                         |
| ------------- | ---------------------------- |
| **手牌皮肤道具id**  | 填入第三步记录的**新道具id**            |
| **手牌皮肤名称**    | 填入第二步获取的**皮肤名称**             |
| **手牌皮肤卡面图路径** | **不配置（留空或保持默认）**             |
| **D~K 列**     | 将路径中的拼音名称部分替换为第二步获取的**命名拼音** |


#### 4.4 保存

保存 CardSkin_手牌皮肤表.xlsx。

### 第五步：输出结果

在飞书中输出配置摘要：

- ✅ 已新增道具（Item.xlsx）：道具id=xxx，道具名称=xxx，品质=xxx
- ✅ 已新增手牌皮肤（CardSkin_手牌皮肤表.xlsx）：皮肤名称=xxx
- ⚠️ 注意：未配置卡面图路径，需后续手动补充

## 注意事项

1. **备份**：修改 Excel 前建议先 git commit 或手动备份
2. **道具id 连续**：确保新道具id = 最大道具id + 1，不要跳号
3. **拼音替换**：icon 图标路径和 CardSkin D-K 列中的拼音名称需要**完整替换**，不是拼接
4. **卡面图**：新皮肤的卡面图路径暂不配置，标注提醒用户后续手动添加
5. **Excel 文件格式**：操作 xlsx 建议使用 Python openpyxl 库或 WPS/Excel 手动操作
