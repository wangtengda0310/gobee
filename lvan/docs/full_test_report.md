### 跳过策略
所有需要真实数据库连接的测试都实现了优雅的跳过机制：

```go
defer func() {
    if r := recover(); r != nil {
        t.Skipf("无法连接到MySQL数据库，跳过测试: %v", r)
    }
    if datasource != nil {
        datasource.Close()
    }
}()
```
