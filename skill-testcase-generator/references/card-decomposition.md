# 牌拆解逻辑（规则参考）

> **本文件的角色**：被测对象为「牌」时的拆解规则，所有牌通用。与 [skill-decomposition.md](skill-decomposition.md) 是平行路径（被测对象判定见 SKILL.md 1.1），共享 [sheet-structure.md](sheet-structure.md) 的牌类型层级快照、[test-point-knowledge.md](test-point-knowledge.md) 的机制定义、[testcase-format.md](testcase-format.md) 的 8 列约定。

**模块清单走五档结构**（与技能侧对偶）：

```
[1] 牌定义档（核心，⚠️ 临时；待 PM 在 hYAw0h 补正式版）
    └─ 4 子模块作"一级模块"列：身份 / 打出条件 / 效果 / 响应
    └─ 拆-NN 原子项强校验：每个 ID 必须出现在某条用例的「拆解项」列

[2] 通用必跑（4 个，与文案无关；按适用判定，不适用整块跳过）
    └─ 发动者和目标者状态 / 与技能交互 / 断线重连 / 边缘场景

[3] 源表现读（hYAw0h，PM 增量自动接入）
    └─ 牌的状态（当前；未来 PM 增加自动接入）

[4] 自由补充（末尾，可选；模型按需自拟一级模块名）
    └─ 极少数 PM 未规定的特殊场景

[5] 机制测试点（追加段）
```

**核心流程**：

```
§1 牌身份采集
  → §2 文案拆原子项（带 ID）
    → §3 五档模块清单
      → §4 各档展开规则
```

> 与技能侧的对偶：技能定义档 5 子模块（发动阶段/发动条件/发动方式/发动效果/重置时机）↔ 牌定义档 4 子模块（身份/打出条件/效果/响应）。两侧"核心档"都遵守 testcase-format.md 列映射规则：用例表「一级模块」列填子模块名，**不写"牌定义"本身**。

## 1. 牌身份采集

在「牌」sheet（`a109ea`）「牌名称」列搜索牌名 → 命中行号 R，逐列取：

| 字段 | 列 | 备注 |
|---|---|---|
| 牌名 | A | 即被测对象名 |
| 牌类型大类 | B | 行动牌/战法牌/装备牌/无类型牌 |
| 牌类型小类 | C | 可空（大类即叶子时空） |
| 花色 | D | 可空 |
| 点数 | E | 可空 |
| 效果文案 | F | **牌的真实定义**，拆解输入 |

文案中的引用走与技能侧 1.2 同款反向查表（牌名/术语/技能/机制），但**跳过 sub_skills 与关联技能集合**——牌不持有/授予技能。命中的术语/牌/机制定义并入 overview「核心术语」「测试点背景知识」section。

## 2. 文案拆原子项（带 ID）

把文案按**动词序列**切成原子项：每个目标限定、动作、数量、代价、效果各成一项，分配 `拆-NN` ID。

**worked example — 削弱冲杀**「对攻击范围内的一名其他角色打出，弃置1张牌，然后对其造成1点伤害。」：

| ID | 原子项 | 类型 | 归入子模块（见 §3.1） |
|---|---|---|---|
| 拆-01 | 攻击范围内 | 目标限定（距离） | 打出条件 |
| 拆-02 | 一名其他角色 | 目标限定（身份） | 打出条件 |
| 拆-03 | 打出 | 动作 | 打出条件 |
| 拆-04 | 弃置1张牌 | 代价 | 打出条件（前提）+ 效果（执行）**双归类** |
| 拆-05 | 造成1点伤害 | 效果 | 效果 + 响应（被闪响应展开） |

**worked example — 杀（普通）**「对攻击范围内的一名其他角色打出，对其造成1点伤害。」拆-01/02/03/05（无代价行）。

动作类原子项（打出/弃置/造成伤害/获得/转化/响应/抵消…）按语义匹配「基本术语」三组动作词汇表（牌与牌堆操作 A58:A70 / 卡牌使用与效果 A71:A86 / 状态效果与属性标签 A133:A152），匹配规则同 `skill-decomposition.md` §1。术语名是参数化形式（如「当xx牌」），靠语义匹配、不靠字面搜。匹配到的术语即该原子项的「关联文档/来源」。

> **拿不准就标注**：拆错模块或多个动作词都可能命中时，「关联文档/来源」列写 `待确认：X 或 Y`，不强行二选一。

**双归类规则**（同技能侧 §2）：一个原子项可同时归入两个子模块（典型：代价），此时**算作两个测试义务、各分配一个 ID 或共用一个 ID 各落两行**，两处都生成用例。例如 拆-04「弃置1张牌」：前提「有牌可弃」归打出条件、执行 + 数量边界（弃 0/1/超出）归效果。

## 3. 一级模块清单（五档）

### 3.1 牌定义档（核心，⚠️ 临时）

4 子模块在用例表「一级模块」列填入（**绝不写"牌定义"**，参照技能侧"绝不写技能定义"规则）：

| 子模块 | 含义 | 归类规则 |
|---|---|---|
| **身份** | 牌身份字段验证 | 每个非空字段（牌名/牌类型/花色/点数/文案）各 1 条用例，验证与源文档 `a109ea` 第 R 行一致；身份用例的「拆解项」列填 `—` |
| **打出条件** | 规则前提：何时/在何条件下可打出 | 拆-NN 中所有目标限定/动作/代价（前提侧）类原子项归此 |
| **效果** | 动作执行后的实际效果 | 拆-NN 中所有伤害/状态附加/牌堆操作/代价（执行侧）类原子项归此 |
| **响应** | 被闪/无懈可击/技能响应抵消 | 仅当被测牌可被响应（杀类/锦囊类）时适用，整块否则跳过；拆-NN 中效果可被抵消的原子项展开 |

**适用判定**：
- 身份：永远适用
- 打出条件：永远适用（除非被测牌是被动响应类如闪/无懈可击——此时整块跳过）
- 效果：永远适用（仅文案完全无效果的极特殊牌跳过）
- 响应：可被响应时适用（杀/锦囊牌等），否则整块跳过；判定按基本术语「卡牌使用与效果」分组里"响应"相关术语 + 文案是否描述可抵消效果

**对应技能侧**：本档对偶技能定义档（5 子模块）。技能侧的"发动阶段"在牌侧不需要（默认出牌阶段，不强枚举 16 节点）；"发动方式"在牌侧大多隐含为主动，不单独成子模块。

> ⚠️ 4 子模块清单标 ⚠️ 临时，**待 PM 在源表 hYAw0h 补"牌定义"正式版后让位**——以源表为权威，本临时清单自动脱落。

### 3.2 通用必跑（4 个）

与文案无关、全卡共通；按适用判定，不适用整块跳过、**不出占位行**。

| 一级模块 | 来源 | 适用判定 |
|---|---|---|
| 发动者和目标者状态 | 源表 `BVTn1E` A7:A10 | 文案涉及主动选目标时适用（杀/锦囊/可指定目标的战法牌）；纯自用（桃自用）、被动响应（闪/无懈可击）、装备自己（武器/防具/坐骑）→ 整块跳过 |
| 与技能交互 | ⚠️ 临时通用 | 永远适用（任何牌都可能触发其它角色的技能） |
| 断线重连情况 | 源表 `BVTn1E` A32:A35 | 永远适用 |
| 边缘场景 | ⚠️ 临时通用 | 永远适用 |

### 3.3 源表现读（hYAw0h）

从 [card-test-point-modules.md](card-test-point-modules.md) 取当前快照（已在 SKILL.md 1.0 刷到最新）。

- 当前：「牌的状态」（含子模块「被锁住状态」「被暴雪天气冻住」），关联术语「冻结」基本术语 C150
- PM 后续新增模块自动接入、无需改 skill 文件
- 与"通用必跑"中已存在的源表模块（发动者和目标者状态/断线重连）按**精确同名让位**——若 hYAw0h 未来加入同名模块，以 hYAw0h 为权威，不重复输出
- 与"牌定义档"4 子模块按同名让位——若 PM 在 hYAw0h 加入"打出条件"等子模块，临时清单让位

### 3.4 自由补充（末尾、可选、极少）

PM 未规定的少数特殊场景，模型按需自拟一级模块名。**靠位置识别**（排在通用必跑、源表现读之后）。

**类目参考**（不强制、不穷举）：

| 类目 | 适用场景 |
|---|---|
| 装备/卸下流程 | 被测牌是装备牌 |
| 触发卜卦 | 卜卦牌 |
| 当xx牌转化 | 其他牌可被技能转化为本牌 |
| 削弱/强化版对比 | 被测牌是基础牌的变体（如削弱冲杀 vs 杀） |
| 视觉/UI 标识 | UI 层差异（如削弱版有特殊边框） |

模型可按需补充或合并；本档使用应**克制**——大多数测试义务应落在 3.1 牌定义档或 3.2 通用必跑里。

### 3.5 排序

测试用例表全局排序：
**牌定义档（4 子模块按 3.1 顺序：身份 → 打出条件 → 效果 → 响应）→ 通用必跑（按 3.2 顺序）→ 源表现读（按 hYAw0h A 列顺序）→ 自由补充（末尾）→ 机制测试点**

## 4. 各档展开规则

### 4.1 牌定义档

#### 身份
- 每个非空字段（牌名/牌类型/花色/点数/文案）各 1 条用例，验证字段值与源文档 `a109ea` 第 R 行一致
- 「拆解项」列填 `—`（身份不对应原子项）

#### 打出条件
对每个归入此模块的 拆-NN 原子项展开正/反/边界用例：
- 目标限定原子项（如「攻击范围内」「一名其他角色」）：满足→可打出 / 不满足→不可
- 动作原子项（如「打出」）：默认时机（行动牌出牌阶段）可用，非默认时机不可用——牌不套用技能侧 16 节点遍历铁律
- 代价原子项（如「弃置1张牌」）前提侧：有牌可弃→可打出 / 手牌不足→不可 / 边界（仅有装备区牌时可否用）
- 「拆解项」列填对应 `拆-NN`；「二级模块」列填原子项内容

#### 效果
对每个归入此模块的 拆-NN 原子项展开：
- 伤害类（如「造成1点伤害」）：伤害数值、伤害类型（属性枚举从基本术语 A133:A152 取）、目标体力变化、致命伤害、击杀判定
- 状态附加类：附加状态原文照搬 + 标来源（如「中毒」「连环」）
- 牌堆操作类（如「弃置」「摸牌」「获得」）：动作执行、数量边界
- 触发事件：造成伤害→受伤事件、获得牌→获得牌事件（与 4.2 与技能交互模块协同）
- 代价的执行侧（如「弃置1张牌」的实际去向）：弃置牌进弃牌堆等
- 「拆解项」列填对应 `拆-NN`

#### 响应（仅适用时）
对每个可被响应的效果原子项展开：
- 杀类被闪响应：闪抵消则伤害归零、已付代价不退
- 锦囊牌被无懈可击响应：无懈可击抵消则效果不结算
- 行动牌被无懈可击响应：默认不生效，写「需游戏内验证」
- 「拆解项」列填对应 `拆-NN`

### 4.2 通用必跑

#### 发动者和目标者状态（仅适用时出）
- 霜冻/乐不思蜀（发动者）：发动者处于此状态时不可选其他角色为目标
- 空城计状态（目标者）：目标手牌为 0 时不可被选为目标（除全体/无主动选目标的效果）
- 调虎离山状态：发动者被对方调虎离山时，不能选其为目标
- 大雾状态：发动者只能选距离 1 以内的目标
- 预期一律照搬源表 `BVTn1E` C 列原文 + 标来源
- ⚠️ 适用判定见 §3.2；不适用整块跳过

#### 与技能交互
- **出牌触发**：本牌打出时触发"出牌时""出杀时"类技能（如赵云枪出如龙、武圣义绝）
- **弃牌触发**：代价弃置触发"弃置牌时"类技能
- **受伤触发**：本牌造成伤害触发目标"受伤时"类技能（不造成伤害的牌跳过此子项）
- **当xx牌**：其他牌可被技能转化为本牌时验证转化后行为
- **技能封禁状态下打出**：被封禁的发动者打出本牌（封禁限制技能发动、不限制打出牌）
- 子项按文案是否触及该类技能而定，不触及的跳过

#### 断线重连情况（源表 4 子模块）
- 技能信息上存在技能牌区的显示
- 武将详情中牌的显示
- buff 标记的显示
- 技能的发动持续状态（牌打出过程中断线重连）
- 预期写"重连后状态正确恢复"或"需游戏内验证"

#### 边缘场景
- 目标消失（打出后目标阵亡，伤害是否仍结算）
- 牌堆耗尽（涉及摸牌时无牌可摸）
- 不可弃置牌（如"渠"作为代价时无法弃置）
- 弃置干扰（弃置过程被技能中断）
- 文案不涉及的子项跳过

### 4.3 源表现读

按 hYAw0h 当前模块的 A 列模块名 + B 列子模块名直接生成用例：每个二级模块 ≥1 条用例。C 列有解释的（当前 hYAw0h 多数无）则用例预期照搬。

当前「牌的状态」展开：
- 被锁住状态：测试本牌处于被锁住时无法打出、可弃置的行为（关联机制「冻结」基本术语 C150）
- 被暴雪天气冻住：同上

### 4.4 自由补充

仅当被测牌的某个场景在前 3 档清单中未被覆盖时生成。模块名由模型按 §3.4 类目表自拟（不带后缀，靠位置识别）。每条用例的「拆解项」列：若对应到 拆-NN 原子项则填 ID，否则填 `—`。

## 5. 概念范围枚举触发

只在以下情况触发枚举（写入 overview「概念范围枚举」section、阶段三全覆盖校验）：

| 文案表达 | 枚举 | 不触发条件 |
|---|---|---|
| 「弃置1张牌」「获得X张牌」「转化为牌」无类型限定 | 牌类型层级快照 10 叶子 | 文案明确"手牌"/"装备牌"等限定 → 仅遍历对应子集（同技能侧 §3 牌枚举） |
| 「造成X点伤害」无属性限定 | 不枚举 | 默认通用伤害 |
| 「造成X点伤害」有属性枚举词（任意伤害类型） | 「基本术语」状态效果与属性标签分组 A133:A152 | 单一属性不展开 |
| 「一名其他角色」 | 不枚举 | 不是宽泛概念 |
| 「攻击范围内」 | 不枚举 | 落入 3.1 打出条件子模块按装备/距离展开 |
| 「出牌阶段」（行动牌默认使用时机） | 不枚举 | 牌不套用技能侧 16 节点遍历铁律 |

> 与技能侧最关键的差异：**牌不遍历技能发动阶段 16 节点**。牌只在文案显式提到时间词时才扩展（罕见）。
