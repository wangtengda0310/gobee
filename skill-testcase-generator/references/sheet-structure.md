### 合并结构（两个层级，嵌套）

| 列 | 合并数 | 层级 | 范围语义 |
|----|--------|------|---------|
| A（归属武将） | ~176 | **武将级** | 跨该武将全部技能的全部条目行 |
| B（武将势力） | 19 | **武将级** | 与 A 同范围（势力随武将） |
| C（技能名称） | 若干 | **技能级** | 跨单个技能的多个条目行（仅多条目技能才合并） |
| D（技能分类） | 若干 | **技能级** | 与 C 同范围 |
| E / F | 0 | **条目级** | 每个条目独立一行，从不合并 |

> C/D 仅少量技能有多条目 → **绝大多数技能是单条目**（C 不合并）。多条目技能（如赵云）C 才合并。

### 检索规则（命中技能名后，运行时按实时 merges 解析）

1. 在 C 列命中技能名 → 读该 cell 的 **C 列合并范围** = 该技能的全部条目行（单条目则范围=自身 1 行）。
2. 武将 = 包住这些行的 **A 列合并范围**值（A 范围 ⊇ C 范围，A 跨多技能）。
3. 势力 = B 列合并范围值（同 A）；分类 = D 列（同 C）。
4. 每个条目行各有独立 E（发动方式）+ F（文案）→ 得到条目列表 `[{发动方式, 文案}, …]`。
5. 兜底：真未合并的单行（A 为 null 且不在任何合并范围内）→ 武将标「未标注」。新文档 190+ 处合并已基本覆盖归属，此路径极少触发。

> ⚠️ **不写死任何具体技能的合并范围**。合并每次跑都从内存 merges 映射现解析；本快照只记规则与模式。

### worked example — 赵云（行 31–35）

```
行31  A=赵云 B=蜀汉  C=枪出如龙 D=武将技 E=被动触发 F=出杀，摸1张牌；出杀：打出杀时
行32  A=null B=null  C=null     D=null   E=主动使用 F=你的闪可以当作杀打出。      ← C31:C32 合并
行33  A=null B=null  C=浑身是胆 D=武将技 E=被动触发 F=闪避，你可以立即打出1张杀；
行34  A=null B=null  C=null     D=null   E=主动使用 F=你的杀可以当作闪打出。闪避：打出闪时  ← C33:C34 合并
行35  A=null B=null  C=七进七出 D=武将技 E=被动触发 F=你每累计打出3张杀或闪后…    ← 单条目
```
- 赵云块 = A31:A35 / B31:B35（武将级）。
- 枪出如龙 = C31:C32（2 条目：被动+主动）；浑身是胆 = C33:C34；七进七出 = C35（单条目）。
- E 可空：实测孙策（行 40–41）E=null。
