# 弃官投义技能测试

## 技能定义

| 属性 | 内容 |
|------|------|
| 技能名称 | 弃官投义 |
| 所属武将 | 陈宫 |
| 效果 | 当你在非摸牌阶段获得牌时，每回合每种牌限1次，可以将其中1张牌交给一名其他角色，令其可以对你选择的另外一名其他角色打出此牌，然后你下个摸牌阶段摸牌数+1，若其没有打出，你受到1点伤害。 |
| 触发时机 | 非摸牌阶段获得牌时 |
| 限制条件 | 每回合每种牌限1次 |
| 特殊规则 | 1. 只能将牌交给「一名其他角色」<br>2. 该角色需要对你选择的「另外一名其他角色」打出此牌<br>3. 打出后：你下个摸牌阶段摸牌数+1<br>4. 若没有打出：你受到1点伤害  |

## 测试用例

| 用例ID | 测试点 | 前置条件 | 操作 | 预期结果 |
|--------|--------|----------|------|----------|
| FY-001 | 登场时获得牌触发技能 | 陈宫登场获得初始手牌；场上有角色A和角色B | 获得牌时 | 可以 |
| FY-002 | 摸牌阶段获得牌不触发 | 陈宫摸牌阶段摸2张牌 | 摸牌后 | 不可以 |
| FY-003 | 回合外获得牌触发技能 | 其他角色给陈宫一张♥3桃；场上有角色A和角色B | 获得牌时 | 可以 |
| FY-004 | 本回合已用过同种牌 | 本回合已通过此技能给过1张杀；再次获得1张♣7杀 | 获得杀时 | 不可以（杀已无可用次数） |
| FY-005 | 本回合已用过不同种牌 | 本回合已通过此技能给过1张杀；再次获得1张万箭 | 获得万箭时 | 可以（万箭是不同种牌） |
| FY-006 | 一次性获得多张牌 | 陈宫一次性获得♥3杀和♠5闪；场上有角色A和B | 获得牌时，发动技能 | 可以，弹出选择界面，只能选择其中1张牌 |
| FY-007 | 场上人数不足 | 场上除陈宫外只有1名其他角色 | 获得牌时 | 不可以（无法选择两个不同的目标A和B） |
| FY-008 | 目标B处于大雾 | 陈宫获得1张杀，选择角色A为目标A，角色B为目标B；角色B处于大雾 | 角色A对角色B打出杀 | 可以，杀无效但已打出，陈宫下个摸牌阶段摸牌数+1 |
| FY-009 | 目标A正常打出牌 | 角色A获得♣7杀，角色B在攻击范围内 | 角色A对角色B打出杀 | 可以，杀正常结算，陈宫下个摸牌阶段摸牌数+1 |
| FY-010 | 目标A打出转化牌 | 角色A获得♥3闪，且有技能可将闪当杀 | 角色A将此闪当杀打出 | 可以，以转化后的形式打出 |
| FY-011 | 成功打出-获得奖励 | 角色A成功打出此牌 | 结算完成 | 可以，陈宫下个摸牌阶段摸牌数+1 |
| FY-012 | 未打出-受到惩罚 | 角色A无法（距离不够）或选择不打出此牌 | 结算完成 | 可以，陈宫受到1点无属性伤害 |
| FY-013 | 技能发动前被封禁 | 技能发动前，陈宫技能被料敌合变封禁 | 获得牌时 | 不可以（技能被禁，不触发） |
| FY-014 | 流程中被重置 | 已选择目标A和B，但目标A未出杀；陈宫技能被重置（如击杀触发重置） | 目标A出杀阶段 | 可以（技能已发动），但后续效果（奖励/惩罚）因重置而中断 |
| FY-015 | 目标A受七步七哀限制 | 陈宫获得1张♥3杀，选择角色A为目标A，角色B为目标B；角色A身上有七步七哀状态（不能将非草花牌当成酒打出）；角色A获得♥3杀 | 角色A尝试将♥3杀当酒打出 | 不可以（七步七哀禁止将非草花牌当酒打出） |
| FY-016 | 不同属性杀视为同种牌 | 本回合已通过此技能给过1张普通杀；再次获得1张火杀 | 获得火杀时 | 不可以（普通杀和火杀都是「杀」，共用次数限制） |
| FY-017 | 雷杀同样受限制 | 本回合已通过此技能给过1张普通杀；再次获得1张雷杀 | 获得雷杀时 | 不可以（普通杀和雷杀都是「杀」，共用次数限制）
