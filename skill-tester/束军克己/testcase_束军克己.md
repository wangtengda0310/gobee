# 名将杀技能测试概览

**技能名称**：束军克己
**所属武将**：吕蒙
**武将势力**：孙吴
**技能分类**：武将技

**技能条目（原文）**：
- 条目 条目1（被动触发）：每个角色的回合结束时，若你此回合没有打出过牌，你获得1张杀；回合开始时，你每拥有2张杀，随机添加1张战法牌到你的手牌。

## 核心术语 ⚠️2358更新

| 术语 | 关键变更 |
| --- | --- |
| 添加牌 | 随机池含普通战法牌+卜卦牌（乐不思蜀/兵粮/天雷/地火/久旱/霜冻），不含专属战法牌 |
| 获得牌 | 从牌堆获取具体牌时，牌堆无该牌→不洗牌也不获得。杀耗尽则束军克己第一段无效！ |
| 打出牌 | 主动+响应都算打出。无变化 |
| 摸牌 | 摸牌数>牌堆剩余→先洗入弃牌堆再抽。新增 |
