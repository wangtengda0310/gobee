# 名将杀技能测试概览

**技能名称**：入蜀三策
**所属武将**：庞统
**武将势力**：蜀汉
**技能分类**：武将技

**技能条目（原文）**：
- 条目 条目1（被动触发）：每轮限1次，其他角色的回合开始时，你可以随机添加3张战法牌至其手牌，令其可以立即打出其中1张，然后将另外2张牌交给你，否则销毁这些牌。
