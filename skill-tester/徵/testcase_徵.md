# 名将杀技能测试概览

**技能名称**：徵
**所属武将**：韩娥
**武将势力**：韩
**技能分类**：绑定型buff

**技能条目（原文）**：
- 条目 条目1（被动触发）：获得时/出牌阶段开始时，可以立即打出1张杀，此杀不消耗出杀次数。
