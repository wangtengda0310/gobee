# 名将杀技能测试概览

**技能名称**：角
**所属武将**：韩娥
**武将势力**：韩
**技能分类**：绑定型buff

**技能条目（原文）**：
- 条目 条目1（被动触发）：获得时/每个回合非摸牌阶段首次获得牌后，随机添加1张装备牌至手牌。

## 核心术语

| 术语 | 分类 | 原文定义 | 来源 |
| --- | --- | --- | --- |
| 绑定型Buff | 技能机制与能力变化 | 定义：Buff的持续生效依赖于源技能处于未封禁状态。机制：如果源技能被封禁，该Buff会立即失效（即使其剩余持续时间还未结束）；当源技能解封后，Buff不会自动恢复，通常需要重新施加。 | 基本术语 cFEl74 C99 |
| 获得牌 | 卡牌使用与效果 | 将某张牌加入自己的手牌或装备区 | 基本术语 cFEl74 C73 |
| 摸牌阶段 | 游戏流程 | 当前玩家从牌堆顶部摸两张牌加入手牌，之后进入出牌阶段。 | 基本术语 cFEl74 C30 |
| 每个回合 | 游戏流程 | 指一个玩家的完整行动回合，按顺序包含：摸牌阶段 → 出牌阶段 → 弃牌阶段。 | 基本术语 cFEl74 C29 |
| 首次 | 技能机制与能力变化 | 指定某个具体阶段期间第一次发生的。如本局游戏首次发生、本轮首次发生、本回合首次发生等 | 基本术语 cFEl74 C93 |
| 手牌 | 空间与区域 | 手牌区的牌 | 基本术语 cFEl74 C110 |
| buff | 技能机制与能力变化 | 一种状态效果，通常由各类技能（武将技、伙伴技、羁绊技等）在发动后附加到目标（自身、队友、敌方或全场）身上。它在持续时间内会产生增益或减益影响。根据其与源技能的依赖关系，分为绑定型Buff（依赖源技能）和独立型Buff（不依赖源技能） | 基本术语 cFEl74 C98 |
| 余音 | 单个技能独有术语 | 余音是韩娥的千古留音技能授予的一组绑定型buff（宫/商/角/徵/羽），每种buff拥有独立效果。余音绕梁触发时令目标获得该余音集合。 | 基本术语 cFEl74 C147 |
| 封禁 | 状态效果与属性标签 | 杀附带特殊限制，令目标无法发动技能，默认封禁持续到当前回合结束 | 基本术语 cFEl74 C132 |
| 重置技能 | 技能机制与能力变化 | 使技能恢复到可再次使用的状态，并且清空技能之前发动的累积效果 | 基本术语 cFEl74 C87 |
| 失去/废除技能 | 技能机制与能力变化 | 使目标永久失去技能。失去一般是自己主动删除，废除一般是被别人删除 | 基本术语 cFEl74 C84 |
| 转移技能 | 技能机制与能力变化 | 将一个角色的技能移到另一个角色身上，保持技能的状态不变。 | 基本术语 cFEl74 C85 |
| 复制/刻写技能 | 技能机制与能力变化 | 复制目标一个技能添加到另一个目标身上。原角色的技能不会失去，目标角色获得一个同样的技能。 | 基本术语 cFEl74 C86 |
| 摸牌 | 牌与牌堆操作 | 从牌堆中抽取指定数量的牌加入手牌 | 基本术语 cFEl74 C66 |
| 手牌区 | 空间与区域 | 角色持牌区域，手牌区的牌在出牌阶段和响应阶段可用于打出 | 基本术语 cFEl74 C106 |
| 装备牌类型 | 状态效果与属性标签 | 牌的类型一般分为行动牌、战法牌、装备牌。装备牌细分为武器牌、防具牌、坐骑牌 | 基本术语 cFEl74 C136 |
